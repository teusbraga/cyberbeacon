1. Introdução & Boas Práticas do HTML Moderno

<!DOCTYPE html>

O HTML (HyperText Markup Language) não é apenas para "jogar elementos na tela". Ele fornece a **árvore de acessibilidade (AOM)**, a indexação de motores de busca (SEO) e o significado contextual para navegadores e leitores de tela.

A Regra de Ouro da Semântica
Nunca use uma <div> ou <span> genérica com evento de clique quando existir uma tag nativa como <button>, <a>, <details> ou <dialog>. Elementos nativos vêm com suporte a teclado (Tab e Enter), foco e leitores de tela de graça!
Estrutura Mínima Obrigatória de Qualquer Página Web HTML5 Boilerplate

Esta estrutura é o esqueleto que todo navegador exige para renderizar em modo padrão (evitando o arcaico Quirks Mode).

  • lang="pt-BR": Diz aos sintetizadores de voz para pronunciarem em português.
  • viewport: Garante escalonamento correto em smartphones e tablets.
  • charset="UTF-8": Garante que acentos como "á, ç, õ" não quebrem.
<!-- Declaração do modo padrão HTML5 -->
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título da Página</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Olá, Mundo Semântico!</h1>
  </body>
</html>

14. CSS3 Moderno: Práticas, Padrões & Exemplos Mais Comuns

CSS3 Vanilla & Modern Specs

O CSS evoluiu drasticamente. Layouts que antigamente exigiam centenas de linhas de código, hacks de float, bibliotecas de JavaScript ou dezenas de media queries hoje são resolvidos nativamente com poucas linhas e máxima performance. Abaixo estão os padrões fundamentais do dia a dia de um front-end moderno.

A Filosofia do CSS Moderno
O CSS moderno é **orientado a fluidez e resiliência**, não a tamanhos fixos em pixels. Sempre que possível, prefira layouts intrínsecos (que se adaptam ao conteúdo e espaço disponível usando minmax(), clamp() e auto-fit) em vez de escrever dezenas de @media (max-width: ...) manuais.
1. O Reset Moderno & A Regra de Ouro do Box-Sizing Fundamento Universal

Comparação Visual: O que acontece quando você adiciona padding: 16px em uma caixa com width: 200px?

[Legado] content-box (padrão antigo):
Largura real: 198px!
(160 + 32 padding + 6 borda) Estoura o layout!
[Recomendado] border-box (padrão moderno obrigatório):
Largura real: 160px!
O padding e borda ficam DENTRO do tamanho. 
/* 1. O Reset Universal Obrigatório */
*, *::before, *::after {
  box-sizing: border-box; /* Previne 90% dos bugs de overflow */
  margin: 0;
  padding: 0;
}

/* 2. Suporte suave a rolagem e Dark/Light nativo */
html {
  scroll-behavior: smooth;
  color-scheme: dark light;
  scrollbar-gutter: stable; /* Evita salto de tela ao abrir modais */
}

/* 3. 100dvh resolve o bug da barra de navegação no mobile */
body {
  min-height: 100dvh; /* Dynamic Viewport Height */
  line-height: 1.5;
  -webkit-font-smoothing: antialiased;
}

/* 4. Mídias responsivas que nunca vazam */
img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
  height: auto;
}
2. As 3 Formas Modernas de Centralizar Qualquer Elemento Sem Hacks

Três maneiras limpas e infalíveis de atingir alinhamento horizontal e vertical perfeito:

1. Grid: place-items: center (1 linha)
2. Flex: justify + align center
3. Inset 0 + Margin Auto (Modais) 
/* Método 1: CSS Grid (O mais conciso e elegante) */
.container-grid {
  display: grid;
  place-items: center; /* Centraliza X e Y em uma linha! */
}

/* Método 2: Flexbox Tradicional */
.container-flex {
  display: flex;
  justify-content: center; /* Eixo horizontal */
  align-items: center;     /* Eixo vertical */
}
/* Dica Pro: Se o pai é flex, basta margin: auto no filho! */
.flex-child {
  margin: auto;
}

/* Método 3: Posicionamento Absoluto Moderno com inset */
.modal-dialog {
  position: fixed;
  inset: 0; /* top:0; right:0; bottom:0; left:0; */
  margin: auto;
  width: fit-content;
  height: fit-content;
}

4. CSS Grid Responsivo com auto-fit (Zero Media Queries!) Layout Bidimensional

Redimensione a janela ou veja os cards se adaptarem automaticamente entre 1, 2 ou 3 colunas:

/* A Fórmula Mágica de Grid Fluida Sem NENHUMA Media Query */
.responsive-card-grid {
  display: grid;
  
  /* 1. repeat(auto-fit, ...) calcula quantas colunas cabem sozinho
     2. minmax(min(100%, 280px), 1fr) impede vazamento em telas pequenas
     3. 1fr faz os cards esticarem para preencher o espaço restante */
  grid-template-columns: repeat(
    auto-fit, 
    minmax(min(100%, 280px), 1fr)
  );
  
  gap: 1.5rem;
}

/* Diferença Crucial:
   - auto-fit: estica as colunas existentes para ocupar 100% do espaço livre.
   - auto-fill: preserva os tamanhos e reserva vagas vazias invisíveis. */
5. Tipografia e Espaçamento Fluido com clamp(min, ideal, max) Matemática CSS

O texto abaixo cresce suavemente conforme a largura da tela sem degraus bruscos:

Título Dinâmico Fluido

8. Seletores do Futuro: :has() (Seletor Pai), :is() & :focus-visible CSS Selectors L4

Marque a caixa abaixo. O container pai inteiro muda de estilo via CSS puro sem nenhum JS graças ao seletor :has():

/* 1. :has() — O tão sonhado "Seletor Pai" do CSS */
.card:has(input[type="checkbox"]:checked) {
  background: rgba(6, 182, 212, 0.15);
  border-color: #06b6d4;
  box-shadow: 0 0 15px rgba(6, 182, 212, 0.3);
}

/* 2. :is() — Agrupamento limpo sem repetição de código */
:is(header, main, footer) > .container {
  max-width: 1200px;
  margin: 0 auto;
}

/* 3. :focus-visible — Acessibilidade impecável */
button:focus {
  outline: none; /* Remove anel feio no clique do mouse */
}
button:focus-visible {
  outline: 2px solid #6366f1; /* Mostra foco apenas no TAB (teclado) */
  outline-offset: 3px;
}

15. Folha de Cola: O que NUNCA Mais Usar (Tags Obsoletas)

Cheat Sheet

Se você aprendeu HTML nos anos 2000 ou início dos anos 2010, esqueça essas tags obsoletas e adote os equivalentes modernos em CSS:

Tag Obsoleta (Evite!) Por que foi abandonada? Substituto Moderno Correto
<center> Mistura apresentação visual com dados de conteúdo. CSS display: grid; place-items: center; ou margin: auto;
<font> Impossibilita manutenção centralizada de temas. CSS font-family, font-size e color
<marquee> Péssimo para acessibilidade e distrativo. Animações CSS @keyframes com controle de pausa
<frameset> / <frame> Quebrava o histórico do navegador e a acessibilidade. Componentes modernos, SPAs ou <iframe> pontual
<b> e <i> (sem contexto) Não transmitem significado aos leitores de tela. Use <strong> para importância e <em> para ênfase
<table> para layout Torna a página completamente inacessível e rígida em celulares. CSS display: flex e display: grid
